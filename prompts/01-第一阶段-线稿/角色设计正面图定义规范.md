# 角色设计正面图线稿提示词规范（优化版v2.0）

## 核心术语定义
标准术语：角色正交正面线稿（Character Orthographic Front Line Art）/ 生产级正面线稿规范（Production-Ready Frontal Line Art）
**绝对禁止术语**：三视图、多视图、侧视图、背视图、斜视图、四视图、多视角拼接
底层逻辑定位：聚焦**单张唯一正面视角**的角色线稿标准化绘制，明确线稿技术要求、姿态规范与结构表达，仅输出单一正面正交视图，绝对禁止任何形式的多视图、三视图生成，为原画输出、3D拓扑、UV拆分等下游环节提供统一的单视角正面基准。

---

## 线稿核心定义（四大维度优化+单视角刚性锁死）
### 1. 几何投影规范（Projection Standard）【最高优先级刚性约束】
核心词：Orthographic Front Projection（正交正面投影）、Single View Only（仅单视角）
**线稿适配强制要求**：
- 仅输出单张唯一正面正交视图，**绝对禁止三视图、多视图拼接、侧视图、背视图、斜视图、多视角分栏的任何形式出现**，画面内仅存在唯一正面朝向的角色主体，无任何其他视角的角色轮廓、结构线
- 彻底消除透视缩减（No foreshortening），角色正面各部位线条度量一致，无近大远小偏差，确保线稿轮廓、内部结构的比例精准，适配工业化生产的比例规范
- 画面内无任何视角切换、视角分割、多视角辅助线，全程锁定单一正面正交投影逻辑

### 2. 标准化姿态（Standardized Pose for Line Art）
核心词：A-Pose / T-Pose（线稿专用标准姿态）、Frontal Symmetry（正面对称）
**线稿适配强制要求**：
- 单一正面视角下，肢体呈对称放射状分布，腋下、胯部留足净空，避免肢体遮挡关键结构；手掌朝前或自然下垂，关节（Joints）位置清晰外露，线条明确勾勒关节节点，便于后续拓扑与绑定识别
- 姿态仅适配正面正交视角，无任何侧身、转体、俯仰动作，无任何为多视角展示设计的肢体调整，全程保持角色完全正面朝向镜头
- 绝对禁止为展示多视角结构调整姿态，禁止任何能呈现侧/背视角的肢体动作

### 3. 线稿技术规格（Line Art Technical Standards）
核心词：Technical Line Art（技术线稿）、Constant Line Weight（等粗线重）、Single Canvas View（单画布单视图）
**线稿核心强制要求**：
- 采用等粗封闭线条勾勒，线条粗细均匀（无粗细渐变，特殊标注除外）；禁止添加任何光影、厚涂、素描调子及色彩；线条边界清晰、利落，无模糊、晕染，确保每一条线都可作为后续生产的结构基准
- 单画布内仅存在唯一正面角色线稿，无任何分栏、分块的多视图线稿，无任何小尺寸侧/背视图辅助线稿
- 线条仅服务于单一正面视角的结构表达，无任何为多视角补充的结构线、辅助线

### 4. 结构表达要求（Structural Expression）
核心词：Structural Line Breakdown（结构线拆分）、Clear Silhouette（清晰剪影）、Frontal Structure Only（仅正面结构）
**线稿适配强制要求**：
- 以线条清晰呈现单一正面视角下的角色轮廓剪影与内部结构分割，线条对应真实的物理转折、服饰褶皱、零件缝隙；无多余杂线，结构层次分明，通过线条粗细区分主体与次要细节（核心结构线略粗，辅助线略细，整体保持等粗基调）
- 仅表达正面视角可见的结构内容，绝对禁止为展示背面、侧面结构添加任何不可见的结构线、透视线、展开线
- 禁止任何为三视图、多视图设计的结构拆分表达，全程聚焦正面可见结构的线条呈现

## 标准线稿提示词结构（优化版，精准适配线稿生成+杜绝三视图）
### 正向核心提示词（带权重优先级，严格按顺序排列）
```
(Category): Character Orthographic Front Line Art, single view only, no multi-view
(View): Flat Frontal View, 2D Orthographic Projection, no foreshortening, character fully facing the camera, no turn, no tilt, no side view
(Pose): Standard A-pose / T-pose, symmetrical standing, exposed joints, clear underarm/hip space, frontal only pose
(Line Style): Clean technical line art, constant line weight, high contrast, non-sketchy, closed lines, no gradient, sharp line edges
(Requirements): No perspective, no shading, no color, no background, full body alignment, clear silhouette, structural line breakdown, no redundant lines, no tri-view, no multi-view, no side view, no back view
(Application): For 3D topology, UV unwrapping, original painting production
```

### 反向强制规避提示词（核心杜绝三视图，必须同步使用）
```
tri-view, four view, multi-view, side view, back view, oblique view, perspective view, multiple characters, split canvas, segmented view, auxiliary view, 3D render, shaded, colored, background, scenery, messy lines, blurry edges, broken lines, deformed anatomy, extra limbs, missing limbs, foreshortening, turn around, character rotation
```

## 提示词构造器参数说明（聚焦线稿适配+单视角锁定）
### 1. 姿态选择（线稿专用，全程锁定正面视角）
- A-Pose：线稿首选生产姿态，肩膀结构舒展，便于勾勒肩颈线条，适配3D拓扑与工业级原画生产，**仅正面视角呈现**
- T-Pose：骨骼绑定适配姿态，线稿需重点清晰勾勒关节位置，便于后续3D绑定对接，**仅正面视角呈现**
- Natural Front：气质展示型线稿姿态，线条可适当保留柔和感，重点突出角色设计风格，适配原画展示类线稿，**严格保持完全正面朝向，无任何侧身转体**
> 刚性约束：所有姿态均仅适配单一正面正交视图，禁止任何为多视角展示调整的姿态设计

### 2. 线稿精度（核心参数）
- Technical Line：工业级标准等粗线，线条均匀、边界清晰，适配3D建模、UV拆分、批量生产，为核心推荐选项
- Variable Line：艺术感变粗细线，主体结构线粗、细节线细，适合原画展示类线稿，非工业生产首选
- Draft Line：草图级线稿，线条可保留轻微草稿痕迹，适合设计初稿、快速迭代阶段，不适合最终生产线稿
> 刚性约束：所有精度等级均仅服务于单一正面视图的线稿绘制，禁止多视图精度区分

### 3. 结构重心（线稿重点，仅正面结构表达）
- Anatomy Focus：人体结构重心，线稿重点勾勒正面视角可见的骨骼、肌肉转折线条，适配裸模或简约服饰角色线稿
- Component Focus：零件与层级重心，线稿重点拆分正面视角可见的服饰、配饰的结构缝隙与层次，适合复杂服饰、和风/机械类角色线稿
- Silhouette Focus：轮廓剪影重心，强化角色正面外轮廓线条，简化内部次要细节，适合角色辨识度优先的线稿
> 刚性约束：所有结构重心均仅表达正面视角可见内容，禁止任何为展示侧/背结构的线条补充

### 4. 细节等级（线稿适配）
- High Density：高密度细节线稿，精准勾勒正面视角可见的服饰纹理、配饰细节，适合复杂机械、精细和风服饰等角色
- Medium Density：中等细节线稿，保留正面核心结构与关键细节，去除冗余杂线，为常规角色工业生产标准
- Low Density：极简结构线稿，仅保留正面轮廓与核心结构线条，适合概念设计初期、简化版角色线稿
> 刚性约束：所有细节等级均仅针对单一正面视图，禁止为多视图补充细节内容

## 最高优先级刚性约束红线（违反任意一条，生成结果直接无效）
1.  **单视图绝对锁死红线**：仅允许输出单张唯一正面正交视图，绝对禁止任何形式的三视图、多视图、侧视图、背视图、斜视图、分栏多视角画面，画面内仅能存在一个完全正面朝向的角色主体
2.  **投影规则绝对红线**：全程锁定2D正交正面投影，无任何透视、近大远小、角色转体、俯仰倾斜，角色100%完全正面朝向镜头
3.  **线稿规范绝对红线**：严格遵循技术线稿标准，无色彩、无光影、无填充、无背景，仅保留黑色结构线条，线条封闭清晰
4.  **结构表达绝对红线**：仅表达正面视角可见的结构内容，禁止任何不可见结构的透视线、辅助线，禁止为多视图补充任何线条内容
