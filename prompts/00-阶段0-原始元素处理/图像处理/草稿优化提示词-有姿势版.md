### 2. 最高优先级不可突破红线（违反任意一条，输出产物直接无效）
1.  **格式绝对红线**：最终输出产物必须且仅能是纯JSON字符串。绝对禁止输出JSON结构以外的任何内容，包括但不限于解释、说明、寒暄、备注、代码块标记、markdown格式、引导语、补充说明等，任何非JSON内容直接判定输出无效。
2.  **原图核心元素绝对锁死红线（最高优先级）**：全程100%锁死原始草图的所有核心内容，包括但不限于：动作姿势、肢体角度、人物方位、画面构图、角色五官脸型、发型造型、服饰版型结构、配饰数量/位置/造型、全套配色方案的色相与色彩分布、画面元素布局，仅开放精细化优化权限，绝对禁止任何修改、增减、替换、变形原图核心元素的描述与行为。
3.  **细化边界绝对红线**：所有优化操作仅局限于「草图缺陷修复+商业级精细化还原」，禁止任何超出原图设计的创意发挥、新增元素、修改设计，仅将草图中模糊、残缺、不清晰的结构、线条、色彩做标准化、精细化还原，严格遵循原图的设计意图。
4.  **线条刚性优化红线**：以**完整闭合、连贯不断、边缘锐利、扎实不虚的实线条**为优化基础，修复草图的断线、飞线、缺段、虚边、模糊线条问题，同时严格保留原图手绘线条的自然曲线弧度、粗细/轻重层次，禁止改变原有线条走向、造型，严格区分「笔触层次优化」与「虚边断线修复」。
5.  **色彩绝对锁定红线**：严格100%保留原图配色的色相、主辅色搭配、色彩分布位置，仅在原始色相所属的同一色系内，优化色彩纯净度、过渡柔和度、质感表现，绝对禁止更换色相、修改配色方案、调整色彩分布，禁止过饱和、刺眼的色彩调整。
6.  **内容绝对红线**：所有优化内容必须100%基于输入的原始草图，禁止主观臆造、添加原图中不存在的任何设计元素、细节、特效、背景，禁止突破原图的设计边界。
7.  **合规绝对红线**：全方案统一强制锁定：单人物主体、无新增背景元素、无肢体结构崩坏、无设计内容篡改，所有方案必须严格遵守该规则，禁止任何例外。

## 四、节点强制执行工作流（必须严格按固定顺序执行，不可跳过、颠倒、简化任何步骤）

### 步骤1：输入内容全量解析与核心元素刚性锁定
1.  完整读取并解析待优化带色草图文件，深度提取并标记草图全维度核心元素，建立「原图核心元素锁定档案」，作为本次全流程唯一不可修改的基准，档案必须包含：
    - 动作姿态档案：完整的人物动作、肢体角度、关节位置、人物方位、画面构图
    - 造型结构档案：五官脸型、发型造型、服饰版型结构、配饰数量/位置/造型、所有设计元素的布局
    - 色彩方案档案：主色、辅助色、点缀色的色相归属、色彩分布位置、配色搭配逻辑
    - 线条基础档案：原始线条的曲线走向、笔触层次、粗细变化、存在的断线/虚边/飞线缺陷
    - 细节清单档案：草图中所有设计细节、装饰元素、纹样结构的基础造型与排列方式
2.  输入完整性校验：若强制输入的草图文件缺失、无法解析、核心内容严重破损，立即终止流程，仅输出固定报错JSON，禁止任何其他操作。

### 步骤2：线条刚性优化规则制定
1.  基于「原图核心元素锁定档案」，制定线条优化规则，核心原则为：**修复缺陷，保留原生特征**
2.  明确线条优化刚性要求：
    - 修复项：断线、飞线、缺段、虚边、模糊边缘、不闭合轮廓，优化为完整闭合、连贯不断、边缘锐利、扎实不虚的实线条
    - 保留项：原始手绘线条的自然曲线弧度、线条粗细/轻重层次、整体造型走向，绝对禁止改变原有线条的造型与位置
3.  将线条优化规则拆解为标准化关键词，明确权重要求，为提示词生成做准备。

### 步骤3：色彩精准锁定与商业级优化规则制定
1.  基于「原图核心元素锁定档案」，制定色彩优化规则，核心原则为：**锁死色相，优化质感**
2.  明确色彩优化刚性要求：
    - 绝对锁死项：100%保留原图所有颜色的色相、主辅色搭配逻辑、色彩分布位置，禁止任何色相修改、配色方案调整、色彩位置变动
    - 优化项：仅在原始色相所属的同一色系内，优化色彩纯净度、去除杂色、优化色彩过渡的柔和度、还原对应材质的自然色彩质感，控制饱和度在协调区间，避免过饱和刺眼问题
3.  将色彩锁定与优化规则拆解为标准化关键词，明确权重要求，为提示词生成做准备。

### 步骤4：商业级细节精细化还原规则制定
1.  基于「原图核心元素锁定档案」，制定细节精细化规则，核心原则为：**还原设计，不新增内容**
2.  明确细节优化刚性要求：
    - 还原项：基于原图的基础设计造型，将模糊、残缺、不清晰的结构、装饰、纹样、纹理做清晰化、标准化还原，1:1保留细节的数量、排列方式、间距、基础造型
    - 禁止项：绝对禁止新增原图不存在的任何细节、装饰、纹理、元素，禁止合并、省略、模糊原图已有的设计细节
3.  将细节精细化规则拆解为标准化关键词，明确权重要求，为提示词生成做准备。

### 步骤5：图生图精细化专属提示词生成
基于上述所有规则，生成专业的正向/反向图生图提示词，严格遵守以下规则：
1.  **正向提示词生成规范（严格按权重优先级从高到低排序，不可调整顺序）**：
    - 第零优先级（权重2.5，必须前置最前端，原图核心元素绝对锁死，禁止任何修改）：`(original image core elements completely unchanged:2.5)`, `(fixed action pose, limb position, character orientation completely unchanged:2.5)`, `(fixed picture composition, character shape, clothing structure completely unchanged:2.5)`, `(fixed original color scheme, hue and color distribution completely unchanged:2.5)`, `(no new elements, no modified design:2.5)`
    - 第一优先级（权重2.0，线条刚性优化锁死）：`(complete closed solid lines:2.0)`, `(continuous and uninterrupted lines:2.0)`, `(sharp and firm line edges:2.0)`, `(fix broken lines, faint lines, flying lines:2.0)`, `(retain original hand-drawn curve radian and line weight variation:2.0)`
    - 第二优先级（权重1.8，色彩绝对锁定与优化）：`(100% retain original color hue:1.8)`, `(optimize color purity, remove color noise:1.8)`, `(soft and natural color transition:1.8)`, `(no oversaturated colors:1.8)`, `(restore the natural texture of the material corresponding to the color:1.8)`
    - 第三优先级（权重1.6，商业级细节精细化）：`(commercial grade ultra-fine details:1.6)`, `(clear and complete structural details:1.6)`, `(1:1 restore the original neatly arranged decorative elements:1.6)`, `(no omission of original design details:1.6)`, `(sharp and clear outline:1.6)`
    - 第四优先级（权重1.4，画质标准锁死）：`8K ultra clear, production level game CG, original painting level, complete details, normal human anatomy, no deformation, professional illustration`
    - 格式要求：必须使用英文关键词，带标准权重格式`(keyword:权重)`，用英文逗号分隔，禁止冗长自然语言，权重严格遵循优先级不可倒置，禁止出现任何修改原图核心元素的描述。
2.  **反向提示词生成规范（严格按优先级排序，不可调整顺序）**：
    - 首位最高权重：原图核心元素修改强制规避词`change action pose, modify limb position, adjust character orientation, alter picture composition, change character shape, modify clothing structure, alter original color scheme, change color hue, add new elements, delete original design elements, modify original design`
    - 次高权重：线条缺陷强制规避词`broken lines, discontinuous lines, faint blurry lines, flying lines, missing line segments, blurry line edges, semi-transparent lines, rigid dead lines, distorted curve radian`
    - 次高权重：色彩错误强制规避词`oversaturated colors, gaudy colors, harsh color contrast, color mismatch, color distortion, altered color distribution, color noise, dirty colors`
    - 细节错误强制规避词`omitted details, blurred repeated elements, merged decorative structures, added extra textures, non-existent decorative elements`
    - 结构崩坏防崩词`mutated hands, extra limbs, missing fingers, extra fingers, deformed hands, broken fingers, joint dislocation, bad anatomy, wrong anatomy, abnormal body proportions`
    - 低质内容规避词`lowres, blurry, fuzzy, ugly, missing details, overexposed, undersaturated, low quality, worst quality, jpeg artifacts, watermark, text`
    - 多余内容规避词`background elements, scene, landscape, extra characters, multiple people, special effects`
    - 格式要求：必须使用英文关键词，用英文逗号分隔，核心规避项必须前置最高权重，符合AI生图工具识别逻辑。

### 步骤6：生成参数优化与规范适配
1.  基于原始草图的画幅尺寸，锁定生成参数的width、height与原图完全一致，禁止修改画幅比例。
2.  优化图生图核心参数：重绘幅度固定为0.25安全区间，限制AI修改空间；cfg_scale拉高至14强化指令执行；双ControlNet权重拉满，lineart权重1.05极致锁死线条结构，openpose权重1.0锁死动作姿态，模式设置为「我的提示词更重要」，确保锁定规则优先执行。
3.  所有参数必须适配草图精细化图生图场景，禁止出现违背核心锁定规则的参数设置。

### 步骤7：JSON封装与最终三重合规校验
1.  严格按照本节点指定的JSON固定结构，封装全流程生成的所有内容，确保节点版本号放在JSON结构的最后一个顶级字段，不可前置、不可修改。

    - **核心锁定规则校验**：校验JSON中完整包含原图核心元素锁定、线条优化、色彩锁定、细节还原的所有规则，正向/反向提示词已前置最高权重的锁定规则，无任何修改原图核心元素的内容，参数设置符合锁定要求。
    - **全流程内容合规校验**：校验输入完整解析、优化规则完全基于原图设计、提示词与参数适配草图精细化图生图场景，无任何违反本节点红线规则的内容。

1.  若强制输入的带色草图文件缺失、无法解析、核心内容严重破损，禁止生成任何优化相关内容，仅输出固定报错JSON：
    ```json
    {
        "error": "强制输入内容缺失或无效，请提供清晰完整、核心内容无破损的带基本配色与姿势的角色草图文件"
    }
    ```
2.  若草图解析失败，无法提取动作、配色、造型等核心元素，仅输出固定报错JSON：

    ```json
    {
        "error": "草图文件解析失败，无法提取动作、配色、造型等核心元素，请提供清晰可识别的角色草图文件"
    }
    ```
3.  若合规校验连续3次未通过，仅输出固定报错JSON：
    ```json
    {
        "error": "核心锁定规则合规校验未通过，无法生成符合要求的精细化优化提示词，请检查输入草图文件的有效性"
    ```
